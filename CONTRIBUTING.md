# Contributing

Use [GitHub Issues](https://github.com/nateui/react/issues/new/choose) to report a bug or request a component. Search existing issues first so related reports stay together.

## Report a bug

Include:

- The affected component and the commit or date of the source you copied.
- A small reproduction with code and steps to trigger the problem.
- What you expected and what happened instead.
- Your React, Tailwind CSS, framework, and browser versions.
- Screenshots or error output when they help explain the problem.

Remove credentials, account details, and other private data from reproductions and screenshots.

## Request a component

Explain the task it should support, how it should behave, and what existing components do not cover. Links to a reference interface or a small sketch are useful.

## Questions

Read the [component documentation](https://nateui.com/components) and [installation guide](https://nateui.com/components/installation) for usage and setup. Email [support@nateui.com](mailto:support@nateui.com) for account or purchase questions.

Report security vulnerabilities privately using [SECURITY.md](SECURITY.md).
