# Security

Report suspected vulnerabilities to [support@nateui.com](mailto:support@nateui.com) with the subject **Security report: NateUI React**.

Include the affected component, the source commit or date you copied it, reproduction steps, and the potential impact. A small example using disposable data helps reproduce the issue.

Keep vulnerability details out of public issues and pull requests until a fix or disclosure has been coordinated. Do not include passwords, API keys, session tokens, or customer data in your report.

If you copied component source into an application, compare relevant fixes in [CHANGELOG.md](CHANGELOG.md) with your local copy. Updating another package will not replace component files you copied into your project.
